# YARAWIC — ياراويك

نسخة Home v0 ثابتة بالعربية واتجاه RTL لعلامة ياراويك. تعرض كتالوجًا تفاعليًا مبنيًا من بيانات محلية، وتوجّه الطلب إلى واتساب من دون حسابات أو دفع أو مخزون.

## التشغيل المحلي

```bash
pnpm dev:static
```

يستمع Vite على المنفذ 3000. لبناء الملفات الثابتة:

```bash
pnpm build:static
```

توجد ملفات الموقع في `client/`، وتُنسخ الأصول الثابتة من `client/public/` إلى `dist/public/`.

## محتوى الموقع

- صفحة استقبال عربية RTL، وفلاتر فئات، وشبكة منتجات.
- نافذة تفاصيل بخيارات الحجم/النوع والسعر ورسالة طلب مرتبطة بالخيار إلى واتساب.
- قسم مخمّر الملفوف، خطوات الطلب، التوصيل والاستلام، وروابط العلامة.
- صور المنتجات والشعار المرجعي المرفقة، وخطوط IBM Plex محفوظة محليًا.
- ملف `/manus-routes.json` يعلن مسار الصفحة الرئيسية.

اعتمد المستخدم أسعار وأحجام الكتالوج الحالي وسياسة التوصيل: 1000 ريال داخل صنعاء والاستلام من بيت بوس قرب جولة سد كمران. يُؤكَّد توفر المنتج ونطاق التغطية وموعد التسليم عند الطلب. الشعار الحالي مرجعي منخفض الدقة؛ يلزم ملف أصلي عالي الدقة قبل الإطلاق النهائي.

## النشر

المشروع مجهز للنشر على GitHub Pages عبر GitHub Actions عند كل تحديث على فرع `main`. بعد تفعيل Pages من إعدادات المستودع باستخدام مصدر **GitHub Actions**، سيكون الموقع متاحًا على:

`https://mohammedalhmed.github.io/YARAWIC/`

للمعاينة محليًا:

```bash
pnpm install --frozen-lockfile
pnpm dev:static
```
