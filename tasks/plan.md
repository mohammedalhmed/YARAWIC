# خطة تنفيذ إعادة تصميم YARAWIC

## الهدف

إعادة بناء Home v0 من مستودع GitHub بصريًا بأسلوب Contemporary Arabic Pantry: واجهة عربية RTL حديثة، أوضح في التسلسل، مختلفة عن النسخة السابقة، وتحافظ على وظيفة الكتالوج والطلب عبر واتساب.

## البنية

- `client/index.html`: الهيكل الدلالي، المراسي، SEO، Hero، الكتالوج، المخمّر، الطلب، التوصيل والتذييل.
- `client/public/styles.css`: نظام التصميم الجديد، الخطوط المحلية، شبكة الصفحة، الحالات والتجاوب.
- `client/public/app.js`: بيانات الكتالوج، الفئات، modal، حساب السعر، ورسائل واتساب.
- `client/public/assets/products/`: صور المنتجات الحقيقية.
- `client/public/assets/yarawic-brand/`: الشعار المرجعي وبانر الكتالوج.
- `client/public/assets/fonts/`: Readex Pro وDM Mono محليان للهوية الجديدة.
- `ideas.md`: Design Read ونظام التصميم المعتمد.
- `tasks/redesign-brief.md`: سجل التغيير والعقود المحمية.

## عقد الوظائف

- الفلاتر تعمل على كل المنتجات الثلاثين الحالية في `app.js`.
- كل بطاقة تحتوي زر تفاصيل يفتح modal المنتج.
- نافذة التفاصيل تعرض البيانات المتوفرة فقط، وتتعامل مع الحجم/النوع وتحدّث السعر والرابط.
- زر واتساب يبني رسالة عربية من اسم المنتج والخيار المحدد.
- القائمة الهاتفية، Escape، focus، `inert`، و`prefers-reduced-motion` محفوظة.
- المسارات والمراسي الحالية لا تتغير.

## التحقق

```bash
pnpm check
pnpm build:static
pnpm dev:static
curl -I http://127.0.0.1:3000/
curl http://127.0.0.1:3000/manus-routes.json
```

بعد البناء: التأكد من الصور والخطوط المحلية، ثم معاينة سطح المكتب والهاتف لأن المستخدم طلب إعادة تصميم مرئية.

## حدود الإصدار

- لا دفع، لا حسابات، لا قاعدة بيانات، ولا تغيير في قناة الطلب.
- لا تغيير للأسعار أو حقائق المنتجات دون اعتماد جديد.
- لا صور مولدة للعبوات أو الشعارات؛ الأصول الحقيقية تبقى هي المرجع.
