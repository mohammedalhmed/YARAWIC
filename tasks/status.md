# حالة مشروع YARAWIC — إعادة تصميم Contemporary Arabic Pantry

**آخر تحديث:** 2026-10-01

## ما اكتمل

| المجال | النتيجة |
|---|---|
| استيراد GitHub | تم استيراد مستودع `mohammedalhmed/YARAWIC` إلى مساحة العمل ومراجعة بنيته. |
| إعادة التصميم | تم استبدال لغة الواجهة السابقة بالكامل باتجاه Contemporary Arabic Pantry: Hero غير مركزي، رف كتالوج أوضح، لوحة مخمّر ملفوف، مسار طلب، ولوحة توصيل جديدة. |
| الخطوط | أضيفت Readex Pro وDM Mono محليًا تحت `client/public/assets/fonts/`. |
| العقود المحفوظة | بقيت المراسي، الفلاتر، نافذة التفاصيل، اختيار المنتج، السعر، واتساب، RTL وإتاحة لوحة المفاتيح. |
| قائمة الهاتف | اكتُشف خطأ `display:none` في مراجعة مستقلة وتم إصلاحه داخل media query للهاتف. |
| الفحوص | نجحت `node --check client/public/app.js` و`pnpm check` و`pnpm build:static`، كما أعادت الصفحة وroute manifest والخطوط والصور HTTP 200 على المعاينة. |

## ملفات محورية

| الملف | المسؤولية |
|---|---|
| `client/index.html` | الهيكل الدلالي والتسلسل البصري للصفحة. |
| `client/public/styles.css` | نظام التصميم الجديد والتجاوب والخطوط المحلية. |
| `client/public/app.js` | بيانات المنتجات، الفلاتر، modal، ورسالة واتساب. |
| `ideas.md` | النظام البصري والاتجاه المعتمد. |
| `tasks/redesign-brief.md` | سبب إعادة التصميم والعقود المحمية. |
| `tasks/plan.md` | خطة التنفيذ والفحص. |

## ما يحتاج قرارًا لاحقًا من العميل

1. تسليم ملف الشعار الأصلي عالي الدقة لاستبدال المرجع الحالي.
2. اعتماد نطاق إنتاج حقيقي قبل إضافة canonical و`og:url`.
3. تأكيد أن كل الأسعار والتوفر ورسوم التوصيل لا تزال صالحة قبل الإطلاق النهائي.
4. قرار ما إذا كانت صفحة كتالوج مستقلة أو ربط مباشر بسلة ستكون المرحلة التالية.

## طريقة الاستمرار

```bash
pnpm dev:static
pnpm check
pnpm build:static
```

يبقى مسار الطلب واتساب فقط في هذه المرحلة؛ لا توجد قاعدة بيانات أو دفع أو سلة.
